📚 NCA Toolkit API Referenz

Diese Dokumentation beschreibt die verfügbaren Schnittstellen des No-Code Architects Toolkit. Sie dient als technisches Referenzwerk für die Automatisierung von Medien-Workflows.

Voraussetzung: Alle Endpunkte erwarten einen gültigen x-api-key im Header und Content-Type: application/json.

📝 Transkription (Speech-to-Text)

Das Toolkit nutzt AI-Modelle, um gesprochene Sprache in Text umzuwandeln.

POST /transcribe Live
Konvertiert Audio- oder Video-Dateien in Text. Erzeugt bei Bedarf Zeitstempel für Untertitel.

Spezifikation

Parameter Typ Beschreibung
media_url String Erforderlich. Absoluter Link zur Media-Datei (MP3, WAV, MP4, etc.).
language String Optional. Sprachcode (z.B. "de", "en"). Standard: Automatische Erkennung.

Rückgabe

{
  "text": "Der transkribierte Text...",
  "srt": "1\n00:00:01,000 --> 00:00:04,000\nBeispiel Text...",
  "language": "de"
}

🎥 Video & Effekte

POST /v1/image/convert/video Neu
Erzeugt ein Video aus einem Standbild. Unterstützt dynamische Kamerafahrten.

Parameter

Parameter Typ Beschreibung
image_url String Erforderlich. URL des Quellbildes.
duration Number Dauer in Sekunden. Standard: 5.
zoom_pan Boolean Aktiviert einen sanften Zoom/Pan-Effekt ("Ken Burns"). Standard: false.
POST /v1/video/add/captions
Brennt Untertitel direkt in das Video ein ("Open Captions").

Hinweis: Nutzt SRT-Daten für die Synchronisation.

🎵 Audio & Mixing

POST /audio-mixing
Legt eine Audiospur (z.B. Voiceover) über ein Video mit optionaler Hintergrundmusik.

Parameter

  • video_url: Das Basisvideo (oder Bild-Loop).
  • audio_url: Die primäre Audiospur.
  • audio_vol: Lautstärke der Primärspur (0-100).

🖼️ Bild-Verarbeitung

POST /v1/image/screenshot/webpage
Erstellt einen hochauflösenden Screenshot einer URL.

🤖 MCP Integration

Das NCA Toolkit fungiert als MCP-Server (Model Context Protocol). LLMs können diese Tools direkt aufrufen.

Konfiguration: In der mcp-config.json wird das Toolkit als Command-Line Tool eingebunden, das über den Web-Proxy kommuniziert.
